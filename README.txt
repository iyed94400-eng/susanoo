SUSANOO - mod Fabric 1.20.1 (Java 17, Fabric API 0.92.2)

COMPILER : JDK 17 + Gradle 8.5+, dans ce dossier :  gradle build
Le jar est dans build/libs/ -> .minecraft/mods avec Fabric Loader + Fabric API.
Test : gradle runClient

UTILISATION
- Craft : obsidienne autour, oeil d'ender en croix, etoile du Nether au centre (ou /give @s susanoo:mangekyo)
- Clic droit : invoque (forme 1), puis evolue (forme 2, forme 3)
- Accroupi + clic droit : renvoie le Susanoo
- R : attaque / V : technique speciale (recharge 10 s)
- Il attaque aussi tout seul les monstres proches. Le joueur est invulnerable tant que le Susanoo est actif.
- Pour que le Susanoo parfait detruise les blocs : gamerule mobGriefing true
